# Ведомость занятий

Веб-часть системы содержала страницу "Ведомость". Ее часто использовали старосты: вместо ручного подсчета занятий по Excel-расписанию можно было выбрать преподавателя и получить таблицу занятий за семестр.

Смотреть вход в меню: [`legacy-web/components/navbar.php`](../legacy-web/components/navbar.php#L20).

![Реконструкция страницы ведомости](images/web-statement-mock.png)

## Как это работало

Страница `statement.php` показывала выпадающий список преподавателей, которые встречались в актуальном расписании за последние 31 день. После выбора преподавателя страница вызывала `get_statement_table()`.

Смотреть: [`legacy-web/components/statement.php`](../legacy-web/components/statement.php#L3-L25).

`get_statement_table()` обращалась к MySQL через хранимую процедуру `vedomost`, передавая:

- ФИО преподавателя;
- дату начала периода;
- дату конца периода.

Смотреть: [`legacy-web/functions.php`](../legacy-web/functions.php#L180-L185).

## Что выводилось

Результатом была таблица по занятиям:

- дата;
- время;
- дисциплина;
- группа;
- содержание занятий;
- количество часов по лекциям;
- количество часов по практическим/семинарским занятиям;
- консультации;
- курсовые работы;
- экзамены.

Смотреть формирование колонок: [`legacy-web/functions.php`](../legacy-web/functions.php#L187-L236).

## Практический смысл

Для старост это было удобным способом быстро получить основу ведомости по преподавателю и семестру. Раньше такие данные приходилось собирать руками из расписания: искать все пары, проверять даты, группы и типы занятий. Страница ведомости превращала это в один выбор преподавателя и готовую таблицу.

Это важный пример того, как система стала полезна не только для просмотра расписания студентами, но и для административных задач внутри учебного процесса.

## Ограничения

Реализация была жестко привязана к структуре базы и хранимой процедуре `vedomost`. В коде также был зафиксирован период `2021-01-01` - `2021-07-01`, поэтому для универсального сценария потребовались бы настройки периода, безопасные параметры SQL и отдельное описание схемы БД.
