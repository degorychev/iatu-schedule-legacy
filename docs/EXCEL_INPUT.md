# Входной Excel

Пример входного файла: [`samples/Informatsionnye_sistemy_i_tekhnologii.xls`](../samples/Informatsionnye_sistemy_i_tekhnologii.xls).

Это не нормальная таблица данных, а визуальный документ для людей. Именно поэтому парсер получился эвристическим.

## Наблюдения по примеру

- Основной лист: `Лист1`.
- Используемый диапазон: `A1:Q130`.
- Реальное расписание занимает верхнюю часть листа, ниже идут подписи и пустые области.
- Заголовки групп объединены по две колонки: например `C10:D10`, `I10:J10`, `K10:L10`.
- Есть скрытые или почти скрытые колонки.
- Дата часто находится слева и объединена на блок строк дня.
- Одна пара обычно занимает две строки: дисциплина/тип сверху, преподаватель/аудитория снизу.
- Преподаватель и аудитория часто лежат в одной строке.
- Встречаются аудитории-слова: `Discord`, `УЛК-2`.
- В одной ячейке могут быть разные занятия для разных дат.
- Сокращения дисциплин не всегда единообразны.

## Следствие для парсера

Парсер должен был сначала восстановить логическую сетку расписания из визуальной сетки Excel, а потом разобрать текст внутри каждой ячейки. Это две разные задачи:

1. Геометрия листа: где дата, время, группа и блок занятия.
2. Семантика текста: что является дисциплиной, преподавателем, типом и аудиторией.
