# Samples

В этой папке лежит пример исходного Excel-файла расписания.

- `Informatsionnye_sistemy_i_tekhnologii.xls` - визуальное расписание, похожее на реальные входные файлы.
- `Informatsionnye_sistemy_i_tekhnologii_preview.pdf` - PDF-превью этого файла, созданное для быстрого просмотра без Excel.

Файл полезен для понимания, почему парсер опирался на эвристики: объединенные ячейки, скрытые колонки, пары в две строки, даты отдельными блоками и смешанные строки "преподаватель + аудитория".
