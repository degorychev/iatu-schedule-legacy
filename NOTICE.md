# Notice

Это curated legacy-снимок из двух старых проектов:

- C#-парсер расписания;
- PHP-веб-интерфейс расписания.

Часть исходного кода и ассетов была создана в 2017-2019 годах и сохранена для исторического контекста. Внутри `legacy-web` также есть сторонние frontend-ассеты, которые были закоммичены в исходный проект в стиле того времени.

Перед публикацией из конфигурации были удалены или заменены:

- локальные IP-адреса;
- учебные/локальные пароли;
- значения, похожие на окружение конкретного сервера.

Репозиторий не предназначен для production-запуска без аудита безопасности и обновления зависимостей.
