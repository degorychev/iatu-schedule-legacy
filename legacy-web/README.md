# Legacy Web

PHP-витрина расписания. Эта часть показывала студентам и преподавателям данные, загруженные парсером в MySQL.

## Возможности

- выбор группы или преподавателя;
- расписание на день;
- расписание на неделю;
- расписание кабинета;
- журнал занятий;
- поиск конфликтов в расписании;
- позднее были добавлены отчеты по Discord-занятиям.

## Основные файлы

- `index.php` - точка входа и простая маршрутизация.
- `functions.php` - запросы к базе, сборка HTML-таблиц и проверки конфликтов.
- `components/` - отдельные фрагменты интерфейса.
- `config.php.example` - пример конфигурации подключения к БД.

## Важное

Это исторический PHP-код. Он не является примером современной веб-архитектуры: SQL, HTML и бизнес-логика во многом находятся в одних функциях. Для современной публикации или production-использования эту часть нужно переписывать с prepared statements, шаблонами, строгой валидацией ввода и корректным HTML-экранированием.
